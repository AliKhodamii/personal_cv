# سید علی خدامی — سایت شخصی

سایت شخصی و نمونه‌کار: طراحی سایت فروشگاهی با وردپرس و ووکامرس، به‌همراه تجربهٔ مهندسی.

## نسخه‌ها

نسخه‌ها با **تگ** و **برنچ** گیت مدیریت می‌شوند، نه با کپی‌کردن پوشه‌ها.

| نسخه | جایی که هست | توضیح |
| --- | --- | --- |
| `v1.0` | تگ روی `main` | رزومهٔ کامل: اتوماسیون، اینترنت اشیا، وب و خدمات فروشگاه |
| `shop` | برنچ `shop` | صفحهٔ فروش: مطالعهٔ موردی ونزو، بسته‌های خدمات، فرایند کار، FAQ |

### دیدن یک نسخه

```bash
git switch -c shop origin/shop   # رفتن روی نسخهٔ فروشگاهی
git switch main                  # برگشتن به نسخهٔ رزومه
```

اگر خواستی فقط فایل‌های تگ `v1.0` را ببینی، بدون تغییر دادن شاخهٔ کاری:

```bash
git show v1.0:index.html
# یا یک کپی کامل در پوشهٔ جدا
git worktree add ../cv-v1.0 v1.0
```

### ساختن یک نسخهٔ تازه

```bash
git add -A
git commit -m "توضیح تغییر"
git tag -a v1.2 -m "نسخهٔ ۱.۲"
git push origin main --tags
```

## ساختار

```
index.html          صفحهٔ اصلی (همهٔ بخش‌ها در یک فایل)
css/style.css       استایل‌ها
js/script.js        سوییچ بخش‌ها و منوی موبایل
.htaccess           HTTPS، کش، فشرده‌سازی
robots.txt          راهنمای خزنده‌ها
sitemap.xml         نقشهٔ سایت
assets/images/      تصاویر و پیش‌نمایش پروژه‌ها
assets/icons/       فاوآیکون
resume.pdf          رزومهٔ قابل دانلود (نسخهٔ اصلی)
```

## پیش از انتشار روی دامنه

1. `robots.txt` و `sitemap.xml` → `https://example.com` را با دامنهٔ واقعی عوض کن.
2. در `index.html` جلوی تگ `canonical` و متاتگ‌های `og:*`، آدرس دامنه را بگذار.
3. `og-preview.svg` را به PNG تبدیل کن. تلگرام و واتساپ تصویر SVG را برای
   پیش‌نمایش لینک نشان نمی‌دهند و PNG لازم دارند (۱۲۰۰×۶۳۰).

## تماس

راه ارتباطی سایت فقط **تلگرام** است (`t.me/alikhodamii`). هیچ فرم یا آدرس
ایمیلی در صفحه نیست، پس سایت کاملاً استاتیک می‌ماند و به PHP نیاز ندارد.

## اجرا روی سیستم خودت

فایل `index.html` را مستقیم باز کن، یا برای اینکه همه‌چیز مثل محیط واقعی کار کند:

```bash
python -m http.server 8123
```

سپس <http://localhost:8123> را باز کن.
